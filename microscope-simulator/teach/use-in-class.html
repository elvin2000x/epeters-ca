Use it in class

Everything you need to run a lesson from a projector or on student devices.

Project it

Open the lesson plan on your own screen and the explorer page on the projector. Each step's link opens the exact view the step talks about.

Use your browser's zoom (Ctrl and plus, or Cmd and plus) to make text bigger for the back row. The explorer pages resize to fit.

Keyboard works everywhere: in the cells view arrow keys turn the cell, plus and minus zoom, 0 resets and L shows labels; in the atom viewer [ and ] step through the elements; in the periodic table arrow keys move between elements and Enter opens a card.

Share a link or a QR code

Every step in a lesson has a Copy link button and a QR code button. Post the link in your class page, or put the QR code on the projector so students open the same view on their own devices.

QR codes are drawn on your own device. Nothing is sent anywhere to make them.

If you are running the explorer from your own computer (an address that starts with 127.0.0.1 or localhost), student devices cannot open that address. Share links from the hosted version instead.

Without internet

If you run your own copy (python serve.py, then open http://127.0.0.1:8845), the explorer and this hub work with no internet connection: every page, font, 3D library and data file is served from that copy, and each page's security policy blocks files from any other site. The hosted version needs a connection to load.

Accessibility, in short

Hub pages use real headings, labelled form controls, a skip link, visible keyboard focus, light and dark themes, and a print layout.

Explorer pages can be used by keyboard, give a text description of each 3D view, list cell parts as text, show a simpler view when 3D is not available, and pause motion when your device asks for reduced motion (microscope).

3D views are visual by nature. For students who use a screen reader, use the text description and the parts list on each page, and the worksheets, which do not depend on seeing the 3D view.

Free, no accounts, no tracking

The explorer and this hub are free. There are no accounts and no sign-up. No page includes analytics or tracking code. The only things saved on a device are two display settings in the browser: light or dark theme, and whether cell labels are on.

The explorer is a draft and its science has not yet been reviewed by a biologist. Each fact names its source so you can check it.
