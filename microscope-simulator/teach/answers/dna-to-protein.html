Answer key · Lesson 8

DNA to protein

Lesson plan Worksheet

  1. Write the partner strand for CGCGAATTCGCG. Then read your partner strand from right to left. What do you notice?

    Partner strand: GCGCTTAAGCGC. Read right to left it is CGCGAATTCGCG, the same as the first strand. That is why the structure file holds two copies of the same strand. Sources: [1, 2]

  2. Which element forms the DNA backbone together with sugar? How do you know from the explorer?

    Phosphorus, in the phosphate groups. When phosphorus is lit up, the gold atoms run along the outside of both strands. Sources: [1, 3]

  3. Template strand: TAC CGT AAA GGC ATT. Write the mRNA.

    AUG GCA UUU CCG UAA Sources: [4]

  4. Circle the start codon and the stop codon. How many amino acids are in the protein? What is the first one?

    Start AUG, stop UAA. Four amino acids (AUG, GCA, UUU, CCG); the first is methionine. Sources: [5, 6]

  5. Delete the first G of GGC in the template and transcribe again in groups of three. What changes?

    New template TAC CGT AAA GCA TT gives mRNA AUG GCA UUU CGU AA. The reading frame shifts: the fourth codon changes from CCG to CGU, and the UAA stop codon is lost, so the protein changes from that point on. Sources: [5, 4]

  6. How many coding nucleotides does each chain need, counting three per amino acid plus a three-letter stop codon?

    Insulin chain A: 21 amino acids, 21 x 3 + 3 = 66. Insulin chain B: 30, 93. Lysozyme: 129, 390. (A simplified count that treats each chain as read from its own stretch of mRNA.) Sources: [7, 8, 5, 6]

Exit ticket. An mRNA reads AUG UUU GGC UGA. How many amino acids does it code for, and which codon stops it?

Three amino acids (AUG, UUU, GGC); UGA is the stop codon. Sources: [5, 6]
